How it works

  1. The interview

    Claude asks the right questions: the business, its customers, the mood, sites the owner likes, what makes the place unique, and what the site must do.

  2. Choosing the world

    Several visual directions open in the browser. The owner picks one, and the site is built in that world by the impeccable design skill.

  3. Checked and live

    An independent reviewer checks it; it follows French law, is built for Google, and goes live for free. Nothing is made up: anything missing is flagged.

Install in a minute

/plugin marketplace add pbakaus/impeccable
/plugin install impeccable@impeccable
/plugin marketplace add mamyrva/site-commercant
/plugin install site-commercant@site-commercant
/reload-plugins

Then, in Claude Code: /site-commercant followed by one sentence about your business. Requires Claude Code and a Claude subscription.
